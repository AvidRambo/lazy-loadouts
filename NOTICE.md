# Data sources

The plugin's code is BSD 2-Clause (see `LICENSE`). The data it ships with in
`src/main/resources/com/lazyloadouts/` is built by `scripts/build_activities.py` from these sources.

## Old School RuneScape Wiki

`activities.json` is derived from the "Recommended equipment" tables of the
[Old School RuneScape Wiki](https://oldschool.runescape.wiki), whose text is licensed
[CC BY-NC-SA 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/). The same licence applies to
that file.

Monster types and elemental weaknesses come from the data the wiki publishes for its DPS calculator,
[weirdgloop/osrs-dps-calc](https://github.com/weirdgloop/osrs-dps-calc).

## Loadout Lab

`requirements.json` (the skill levels needed to equip an item) is derived from
[Loadout Lab](https://github.com/AKAddons/runelite-loadout-lab), which in turn derives it from
